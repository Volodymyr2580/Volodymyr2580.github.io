跨网络连不上？配置中转服务

默认使用直连，不含可用的 TURN 中转账号。校园网、公司网或部分移动网络可能限制直连。如果有自己的 TURN 服务，可在两端分别填写；设置仅保留在当前页面，刷新后清除。

连接设置（开始连接前填写）

连接失败也可以让两台电脑接入同一 Wi-Fi 或手机热点，并检查 VPN、访客网络及设备隔离设置。

文件如何传输？能传多大的文件？

配对通过公共 PeerJS 信令服务建立连接；文件通过 WebRTC 加密传输。默认不配置中转，文件直接在两台设备间传递。配置 TURN 后，中转服务器会转发加密流量，并可能产生流量费用。

桌面 Chrome / Edge 在支持保存接口时，可边接收边写入硬盘，适合大文件。其他浏览器采用内存接收，本页所有待下载文件合计限制为 128 MiB；下载后可清空记录释放空间。暂不支持文件夹、断点续传或离线投递。中断后请重新发送。

配对需要互联网，两端必须同时在线。邀请链接和配对码相当于临时钥匙，请勿公开。信令服务和 STUN / TURN 服务会接触连接所需的网络信息。此页面不加载网站统计脚本，不在服务器存储文件或传输记录。

传输速度取决于实际网络与硬盘，没有固定速率保证。首次使用，建议先传一个小文件确认连接。
