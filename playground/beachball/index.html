如何读这张图？

北在上、东在右。圆心是竖直向下的射线（出射角 0°），圆周是水平方向（90°）。P/T 轴显示下半球端点，读数为方位角 / 俯角；竖直轴的方位角没有定义。

深色区域与 + 表示沿射线向外的压缩初动，白色区域与 − 表示向内的膨胀初动。两条节面上理论 P 波振幅为零。图上的 + / − 是示意采样，金色圆点用于精确探查。

P/T 是震源的主轴，不是初动区的名称。在此符号约定下，T 轴落在压缩初动区，P 轴落在膨胀初动区。它们也不能直接等同于区域构造应力轴。

实线是输入断层面，虚线是辅助面。仅凭机制球无法判断哪个节面是真实断层；倾角为 0° 时，走向与滑动角的参数表达不唯一。

计算约定与开源参考

采用 Aki–Richards 走向 / 倾角 / 滑动角约定与北–东–下（NED）坐标。单位滑动向量 s 与单位法向量 n 构成双力偶矩张量：M = s nᵀ + n sᵀ；方向 r 上的相对 P 波辐射系数为 A = rᵀ M r，范围为 −1 至 +1。

P 与 T 分别对应 M 的最小、最大特征值。球面使用 Lambert 等面积投影。此工具只描述纯双力偶与震源处的理论 P 波辐射，不包含传播路径、自由表面或仪器响应；读数不是地表记录振幅。

开源参考：ObsPy Beachball 与 MoPaD（LGPL-3.0）。浏览器端独立实现向量几何，数值核对使用 ObsPy。读图背景参考 USGS 的机制球说明。
