# 网站双语内容维护

网站使用现有 Jekyll 模板提供简体中文和 English，不需要额外的 Jekyll 插件。

## 语言选择

第一次访问时根据浏览器语言选择中文或英文。访客手动选择后，偏好保存在浏览器中，刷新及跨页访问继续生效。浏览器禁止保存数据时，本页仍可切换语言，但无法记住选择。

## 添加译文

`_data/i18n.json` 保存两种语言。每个条目的键是稳定标识；目前多使用原始文案作为键，也可以为新文章采用 `article.slug.paragraph1` 这样的标识。

```json
{
  "article.example.heading": {
    "en": "Research Notes",
    "zh-CN": "研究笔记"
  }
}
```

在页面中标记对应的纯文本元素：

```html
<h2 data-i18n="article.example.heading">Research Notes</h2>
```

标签内部只放纯文本。链接、图片、代码、公式和子标签应保持独立，不能把整个复杂容器标为翻译目标；切换语言会替换该元素的文字。无 JavaScript 时显示标签内的默认文案。

页面标题的翻译以 front matter 中 `title` 的完整原文为键。新增导航或修改个人简介后，也请同步补充字典。可访问性标签使用 `data-i18n-aria-label`。

## 文章翻译进度

页面标题、说明与完整正文都翻译完毕后，才在 front matter 添加 `bilingual: true`。没有该标记的页面显示“暂以原文呈现”的提示；已有链接和原文保持可访问。

当前已覆盖主页、学术成果、荣誉奖项、博客及保留的分类页，以及博客《从反演问题到生成模型：为什么我开始重新理解“先验”》的全文。其余历史博客、日记、笔记和研究长文仍需逐篇校对并添加完整译文；中文原文可保留在字典的 `zh-CN` 字段。

不要用语言切换改写数学公式、代码、论文题名或研究结论。论文题名、人名、软件名和必要的学术缩写可保留原文。所有文件使用 UTF-8。

评论组件通过 giscus 官方的 `setConfig.lang` 消息同步界面语言；不改动评论内容及讨论映射。

## 检查

修改后检查中文和英文两种状态、刷新、跨页跳转、手机宽度、文章原文提示，并核对公式和链接。正式发布前运行 Jekyll 构建；仅浏览器交互检查不能替代生成器验证。
