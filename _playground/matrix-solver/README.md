# Matrix Lab · 矩阵求解器

Playground 中的实矩阵计算工具。先选择行数 $m$ 和列数 $n$，再输入矩阵；方阵计算逆矩阵与特征值分解，非方阵计算 Moore–Penrose 伪逆与薄奇异值分解。计算在浏览器本地进行，不上传矩阵数据。

## 安装、测试与预览

需要 Node.js 和 npm。在本目录打开终端，运行：

```powershell
npm ci
npm test
npm run build
npm run dev
```

`npm ci` 根据已提交的 `package-lock.json` 安装固定依赖。`npm run dev` 会先构建一次，再启动仅监听本机的预览服务：

[http://127.0.0.1:4174/playground/matrix-solver/](http://127.0.0.1:4174/playground/matrix-solver/)

如端口被占用，可先设置 `$env:MATRIX_PORT = 4175`。修改源码后需要重新构建，再刷新浏览器；此服务没有自动热更新，也不会编译 Jekyll 主站页面。不要直接双击 HTML，浏览器模块和 Worker 需要通过 HTTP 加载。

## 输入与操作

- 行数与列数分别支持 1–50，最大为 50 × 50。
- 只接受有限实数；允许零，非零数值的绝对值范围为 $10^{-150}$ 至 $10^{150}$。
- 可以输入小数、科学计数法和单个分数，例如 `-2.5`、`1e-6`、`1/3`、`-2e3/5`。分母不能为零，不执行任意表达式，也不接受复数输入。
- 逐格填写，或整块粘贴。列可以用空格、Tab 或逗号分隔；行可以用换行或分号分隔，允许最外层的一对方括号。粘贴矩阵必须与已生成的 $m \times n$ 尺寸一致。
- 更改维数后，点击“生成矩阵”应用新尺寸。修改输入会清除旧结果，避免把旧矩阵的结果当作新结果。
- 内置对称、长矩阵、宽矩阵、奇异、复数特征值和 Jordan 块示例，也可填入单位对角、随机整数或零矩阵。
- 点击“计算分解”，或按 `Ctrl+Enter` / `Cmd+Enter`。计算期间可以取消；超过 12 秒会终止本次 Worker 并提示超时。

## 计算结果

对于方阵，数值上满秩时显示普通逆矩阵 $A^{-1}$、特征值及特征向量。实矩阵的特征值可能为复数，因此输出允许复数；特征向量按列排列，满足：

$$
AV = V\Lambda.
$$

只有获得可靠的可逆特征向量基时，才同时给出 $V^{-1}$ 和对角化形式：

$$
A = V\Lambda V^{-1}.
$$

对于数值奇异的方阵，普通逆矩阵不可用，会明确说明并提供伪逆作为补充；伪逆不会标作普通逆矩阵。特征值计算与逆矩阵是否存在相互独立。

对于非方阵，令 $k=\min(m,n)$，输出薄 SVD：

$$
A = U\Sigma V^{\mathsf T},
\qquad
U\in\mathbb R^{m\times k},\quad
\Sigma\in\mathbb R^{k\times k},\quad
V^{\mathsf T}\in\mathbb R^{k\times n}.
$$

伪逆 $A^{+}$ 的尺寸为 $n \times m$，使用相同奇异值截断规则计算。页面还显示数值秩、条件数和验证误差，包括逆矩阵乘积、特征对残差、SVD 重构与正交性，以及伪逆的四个 Moore–Penrose 条件。

## 精度与数值边界

所有计算采用 JavaScript 的 IEEE 754 双精度浮点数。算法先按矩阵最大元素绝对值缩放，以改善统一极大或极小数值的计算，再把结果恢复到原尺度。数值秩采用默认阈值：

$$
\tau = \max(m,n)\,\varepsilon\,\sigma_{\max},
\qquad
\varepsilon = \texttt{Number.EPSILON}.
$$

仅保留严格大于 $\tau$ 的奇异值。低于阈值的方向会被视为数值零，因此这里的“秩亏”和“普通逆不可用”是当前浮点精度下的判断，不是符号代数证明。

同样，“未获得可靠的数值对角化”可能来自缺少独立特征向量，也可能来自特征向量基严重病态。当前实现要求基满秩、基的条件数不超过 $1/\sqrt{\varepsilon}$，且归一化特征对残差小于 $10^{-8}$，才提供对角化结果。Jordan 块等缺陷矩阵不会被误标为已有可靠对角化。

界面的有效位数只控制显示，不重新计算矩阵。单个矩阵复制和“复制全部”使用未按显示位数舍入的双精度结果；它仍是浮点精度，不是精确分数。若浏览器拒绝写入剪贴板，会显示可手动复制的文本。

下载 JSON 保留原始输入、计算结果和精度元数据。复数编码为 `{ "re": ..., "im": ... }`；条件数等非有限标量会编码为字符串，例如 `"Infinity"`，不会被 JSON 静默改为 `null`。

## 文件与构建约定

- `_playground/matrix-solver/`：可维护源码、依赖锁定文件与测试。
- `src/input.js`：维数、数值和整块粘贴校验。
- `src/engine.js`：逆矩阵、伪逆、EVD、SVD 与数值诊断。
- `src/worker.js`：独立计算线程入口。
- `src/main.js`、`src/result-view.js`、`src/locale.js`、`src/style.css`：交互、结果展示、中英文文案与样式。
- `tests/fixtures/reference.json`：独立 NumPy 参考值及其来源记录。
- `scripts/build.mjs`：将应用打包到仓库的 `playground/matrix-solver/`，不清空目录或批量删除文件。

发布目录包含 HTML、CSS、打包后的应用和 Worker，以及数值库许可文件。运行页面不依赖在线 CDN，也不需要后端数值服务。测试、README、开发脚本和 `node_modules` 不属于发布产物。构建成功只表示本地产物生成，不能证明 GitHub Pages 已上线。

## 依赖、许可与验证

依赖固定为 `ml-matrix 6.15.1` 和构建工具 `esbuild 0.28.2`。数值库文档与源码见 [mljs/matrix](https://github.com/mljs/matrix)。两项第三方依赖均采用 MIT 许可证；构建脚本把 `ml-matrix` 的许可复制为发布目录中的 `assets/ml-matrix-LICENSE.txt`，并保留打包器提取的许可注释。这里不另外改变个人主页代码的许可约定。

截至本次实现，`npm test` 共 **42 项测试通过**：15 项数值单元测试、3 项输入校验测试、24 项独立参考测试。独立参考值由现有 Python 3.11.7、NumPy 1.26.4 的 LAPACK 数值例程生成，覆盖宽/高/秩亏矩阵、共轭复数谱、Jordan 块、病态矩阵及 $10^{\pm140}$ 缩放；比较逆矩阵和伪逆系数、谱值、重构与定义恒等式，不要求特征向量的符号、相位或排序一致。

这些测试验证所覆盖的数值与输入情况，不代表任意病态矩阵都能获得高精度结果。使用结果时应一并查看条件数、阈值和残差。所有中文文本以 UTF-8 保存。
