# Volodymyr's Planet

一座可以散步的 2.5D 像素科研小岛。四个地点分别介绍雷达与反演、行星科学兴趣、学习笔记和个人生活；正文支持中英文切换。

## 启动与构建

需要 Node.js 22 或更新版本。没有第三方运行或构建依赖，无需安装 npm 包。在本目录运行：

```powershell
npm run dev
```

打开 <http://127.0.0.1:4173/_playground/little-planet/>。本地服务仅监听本机，默认端口为 4173；需要调整时可先设置 `$env:PORT`。

```powershell
npm run check
npm test
npm run build
```

构建会把页面、样式、脚本和图像复制到仓库的 `playground/little-planet/`，保留原有文件，不清空目录。缺少 `island.png`、`explorer.png` 或必要源码时，构建会报错。构建结果可通过 <http://127.0.0.1:4173/playground/little-planet/> 预览，并由现有 GitHub Pages 发布流程托管。

这里的开发服务只读取静态文件，不运行 Jekyll。小岛可以独立预览；在本机预览时，通往首页、博客、笔记和研究页面的链接会打开正式网站。请通过上述 HTTP 地址访问，直接双击 HTML 不适用于 ES 模块。

## 怎么玩

- 用 WASD 或方向键移动，也可以点击可行走的小径。
- 走近地点后按 E、空格，或点击互动按钮。
- 手机上拖动摇杆移动，通过按钮互动。
- 地图可用于选择目的地；探索手册可以直接阅读所有地点内容。
- “回到营地”重置角色位置。脚步、探索和雷达音效默认关闭，可以自行开启。
- 探索进度仅存储在当前浏览器中，不需要账号，也不会上传到服务器。

## 画面与文件

视觉依据是 `design-previews/little-planet/2026-10-13/A-pixel-expedition.png` 中选定的 A 方案。岛屿与角色图像通过内置 `image_gen` 生成，再以本地图像资源加载；运行时不会调用图像生成服务。

- `assets/island.png`：1536 × 1024 岛屿背景；世界坐标与可行走区域以此为基准。
- `assets/explorer.png`：4 × 4 的角色精灵图，每格为一个角色方向或步行动作。
- `src/world-map.js`：手工对齐背景的行走多边形、障碍和地点坐标。
- `src/navigation.js`：行走与路径计算。
- `src/content.js`：四个地点的中英文介绍和真实站内链接。
- `src/main.js`、`src/style.css`：画面、控制、互动与界面。

背景是固定视角的平面图，人物与交互叠加其上。它没有三维旋转镜头或完整物理引擎；修改背景、建筑或精灵图布局时，应同步核对行走区域、遮挡和动作帧。

雷达互动只表示“发射—传播—反射”的定性概念，不是数值正演；动画中的回波间隔、亮度和层位不能作为真实测量或反演结果。极地场景同样是为个人展示设计的想象地图。

所有中文文件使用 UTF-8。构建不会复制测试、开发脚本、README 或生成提示词。
